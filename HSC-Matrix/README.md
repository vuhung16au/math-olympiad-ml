This booklet curates matrix problems adapted from the Queensland (QCAA) Specialist Mathematics syllabus. It serves as an enrichment topic covering matrix arithmetic, determinants, inverses, systems of linear equations, and geometric transformations.

## Overview

The booklet [`HSC-Matrix.tex`](HSC-Matrix.tex) contains:

- An introduction to matrix operations and theory
- Part 1: Worked problem sets grouped by difficulty
- Part 2: Practice and challenge problem bank
